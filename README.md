# Yellow-Grid Removal and ArUco Marker Recovery

This repository is a fork of [`vortex-image-filtering`](https://github.com/vortexntnu/vortex-image-filtering), a ROS 2 image-filtering package developed by Vortex.

My contribution is the `RemoveGrid` filter, a computer-vision algorithm designed to remove a yellow grid that partially obscures an ArUco marker. The remaining filters, framework, and supporting code in this repository originate from the Vortex project unless otherwise stated.

## Problem

When a yellow grid partially obscures an ArUco marker, the standard ArUco detector may no longer be able to identify the marker.


## Solution

The proposed solution removes the grid and reconstructs the marker's obscured parts using image inpainting. The `RemoveGrid` filter processes the image in the following stages:

1. The filter operates only within a configurable rectangular region of interest (ROI) that contains the marker and the grid. The configuration file can adjust the ROI size and rotation. Processing a smaller region reduces the computational cost of the later inpainting operation.
2. A binary mask is generated by thresholding the yellow grid bars in HSV colour space. Testing showed that HSV provided more reliable separation of the yellow grid than RGB from the rest of the image.
3. The mask is then dilated to ensure that the entire grid structure, including edge pixels, is covered. Optionally, apply binary thresholding before inpainting.
4. OpenCV's `inpaint` function estimates the missing image regions using information from the surrounding pixels. This removes the detected grid and reconstructs the obscured parts of the ArUco marker.
5. The reconstructed marker is then published and can be passed to an ArUco detector.

## Testing and Parameter Tuning

The HSV threshold values can either be tuned manually or estimated through randomised search. To enable randomised search, set the `hsv_tuning` parameter in the configuration file to `true`. In this mode, ArUco detection runs directly in the filter program rather than in the external detector. When a marker is successfully detected, the filter writes its ID to a CSV file for later analysis. The filter can be tested in the Stonefish simulator by following the instructions provided in the [Vortex GitHub repository](https://github.com/vortexntnu/vortex-stonefish-sim).
